# interval-recognition (Oct. 28, 2026)
I wrote an interval recognition practice code, mostly using what I have learnt so far in University of Toronto's introductory course to Python. It randomly picks an interval from C major and asks the user to answer what interval it is. The code also keeps track of number of attempts made and correct answers, calculating the overall accuracy of answers at the end.  

I have only taken an introductory course to Python for a month and a half and this was my first time coding something outside of class. So, it was very difficult to to build it, especially so that Python keeps track of the accuracy and ask the user questions again and again until the user tells it to stop.
