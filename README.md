# interval-recognition (Oct. 28, 2026)
I wrote a　Python-based music interval recognition quiz, aiming to help users practice interval identification. I developed this project independently after learning the fundamental skills of Python in the  University of Toronto's introductory programming course (CSC108). 

# Motivation 
When I first started learning music theory in middle school, I had trouble with interval recognition and wanted an interactive ways to practice. After learning Python, I wanted to create a simple quiz that I would have wanted to use. This is also my first independent programming project outside my coursework. 

# Features
- Randomly generates and prints an interval from C major
- Asks the user to input answers
- Provide immediate feedback
- keeps track of number of attempts made and correct answers, calculating the overall accuracy of answers at the end  

 # Future Improvements
 I have not been able to finish this project and it is still a simple text-based quiz. In the future, I want to add audio playback / sheet music visuals to practice interval recognition by ear or through reading music. I also want to expand the range of questions beyond major intervals starting from C. 

# Reflection
Although it was challenging, I gained an experience applying concepts from CSC108 to a problem I had encountered before. Implementing complex loop structure helped me better understand how the functions work in creating an interactive program, as well as the difficulty is debugging.
